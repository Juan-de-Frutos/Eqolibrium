# Eqolibrium
Eqolibrium es una página web que desarrollé, junto con otros compañeros del instituto, para el concurso de emprendimiento Gigas4Schools, llegando a la semifinal de España. Este proyecto busca concienciar sobre los hábitos de vida sostenibles, dando diversos consejos. Pemite hallar tu huella ecológica a través de un cuestionario sobre tus hábitos.
